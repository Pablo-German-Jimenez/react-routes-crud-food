# 🍔 CRUD Food App

Beat it! ♪ https://react-routes-crud-food.netlify.app/ ♪

Bienvenido a **CRUD Food**, una aplicación web desarrollada con React que permite crear, leer, actualizar y eliminar platos o productos gastronómicos. Este proyecto combina una arquitectura modular con navegación fluida gracias a **React Router**, y un diseño visual estilizado con **Bootstrap** y CSS personalizado.

## 🚀 Tecnologías Utilizadas

Este proyecto fue construido con:

- **HTML5** – estructura semántica y accesible
- **CSS3** – estilos personalizados y animaciones
- **Bootstrap 5** – componentes visuales y diseño responsivo
- **React** – arquitectura basada en componentes reutilizables
- **React State** – manejo dinámico de datos en tiempo real
- **React Router DOM** – navegación entre rutas sin recarga de página

## 🧩 Funcionalidades

- 📄 **Listado de productos** con render dinámico
- ➕ **Agregar nuevos platos** mediante formularios controlados
- ✏️ **Editar productos existentes**
- ❌ **Eliminar productos**
- 🔀 **Navegación entre vistas** usando React Router (`BrowserRouter`, `Routes`, `Route`, `Link`)
- 💾 **Persistencia local** con `localStorage` *(opcional)*

## 📦 Instalación

```bash
git clone https://github.com/tu-usuario/crud-food.git
cd crud-food
npm install
npm start
```
